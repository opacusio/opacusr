OpacusR 0.11.0 для Windows x86_64 (сборка windows-gnu)
========================================================

В архиве три программы — это три разные РОЛИ, а не дубли.

1) opacusr.exe — ГРАФИЧЕСКИЙ КЛИЕНТ (то, что запускает человек)
   Подключение к удалённому компьютеру по ID и паролю: просмотр экрана,
   управление мышью и клавиатурой, чат, передача файлов, терминал,
   печать кадра. Здесь же — карточка «Этот компьютер» (хостинг),
   «Найдено в этой сети» и контакты. Запуск: двойной клик.

2) opacusr-agent.exe — ХОСТ-АГЕНТ (служба на компьютере, который ПОКАЗЫВАЮТ)
   Захват экрана, приём ввода, файлы, терминал, режим приватности,
   запись сессий в MP4. Основные команды:
     opacusr-agent.exe run                запуск в консоли и ожидание сессий
     opacusr-agent.exe service install    установить как службу Windows
     opacusr-agent.exe service status     состояние службы
     opacusr-agent.exe service uninstall  удалить службу
     opacusr-agent.exe passwd             пароль без присутствия хозяина
     opacusr-agent.exe id                 показать ID этого компьютера
     opacusr-agent.exe --help             полный список команд
   Режим «нулевая инфраструктура» (без отдельного сервера):
     opacusr-agent.exe run --signal-listen

3) opacusr-server.exe — СЕРВЕР (сигналинг + relay, опционален)
   Нужен, только когда прямое P2P-соединение невозможно (обе стороны
   за NAT) и вы не используете --signal-listen у агента.
     opacusr-server.exe --help

Автозапуск (TeamViewer-модель)
-------------------------------

* MSI-установщик: сам регистрирует службу хост-агента
  (opacusr-agent.exe service install — автозапуск при загрузке Windows,
  сразу стартует) и добавляет OpacusR в автозагрузку пользователя
  (окно стартует свёрнутым в трей, флаг --tray).
* ZIP-архив: автозапуск настраивается одной командой от Администратора:
      opacusr-agent.exe service install
  Служба «OpacusR Agent» сама запускает хост-агент в сеансе каждого
  пользователя (supervisor в Session 0 спавнит агента в активной
  консольной сессии). Статус: opacusr-agent.exe service status.
* В GUI: Настройки → Хост → «Автозапуск» — агент стартует вместе с
  OpacusR; закроешь окно — агент продолжит работать в трее.

Примечание: для подключений без хозяина (unattended) заранее задайте
пароль доступа — служба не показывает диалоги подтверждения:
      opacusr-agent.exe passwd

Почему программ несколько: роли изолированы намеренно. Агент работает
как служба без GUI и без сеанса пользователя, сервер можно вынести на
VPS, а клиент ничего не открывает наружу. В самом GUI-клиенте
подключение и хостинг объединены в одной карточке (дизайн Rev 3: тёмная
тема, фиолетовые акценты) — но бинарники остаются раздельными.

Сборка: mingw-w64 GCC 14; libgcc, libstdc++, Opus и OpenH264
прилинкованы статически — внешние DLL не требуются, используются
только системные библиотеки Windows 10/11.
