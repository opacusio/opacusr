# OpacusR — checkpoint (2026-11-23)

## v0.11.15 SHIPPED (tag re-created on 7f6b13c, CI main success, release run 45100592256 success)

Request: «С ноутбука на телефон пусто. С телефона на ноутбук так же. И
невозможно задать пароль.» — the phone screenshot showed the session
screen with «closed: all signaling endpoints failed (ws://127.0.0.1:8080/
signal: … host unavailable: peer 201024543 is offline)».

Three distinct roots:
1. Phone→laptop by ID: both devices keep loopback signaling defaults —
   the phone never tried the laptop's LAN server. AND the laptop's
   Windows Firewall silently dropped every inbound packet (signaling,
   relay, ICE), so even manual setup could not have worked.
2. Laptop→phone "пусто": Android is viewer-only — MediaProjection
   capture is NOT implemented, so a session INTO the phone renders an
   empty frame stream. Honest note added to the Android host card.
3. «невозможно задать пароль»: dirs::config_dir() is None on Android →
   state silently wrote into unwritable `./opacusr/`. Fixed via
   $OPACUSR_CONFIG_DIR exported from AndroidApp::internal_data_path()
   in android_main; config_root()/data_root() (agent), AddressBook::path
   and SessionSettings::download_dir route through it.

Fix (commits b4248ef + 3fab4ed + 7f6b13c):
- app.rs connect ladder appends every mDNS-discovered signaling URL →
  by-ID works on one Wi-Fi with zero configuration.
- Android MulticastLock via RAW JNI (jni-sys 0.4): jni-sys 0.4 vtables
  are VERSIONED UNIONS via #[jni_to_union] — access is
  (*vm).v1_1.AttachCurrentThread / (*iface).v1_6.Field; jboolean=bool;
  variadic CallVoidMethod takes c_int (bool → E0617); vtable fields are
  NOT Option (no .unwrap()); store the leaked global ref as usize.
  Helper is UNgated so the host build type-checks it + null-handle test.
- MSI firewall: fire:FirewallException for both exes (TCP+UDP, all
  profiles) — MUST carry File='OpacusRExe'/'OpacusRAgentExe' (CNDL6403
  without it); candle AND light need -ext WixFirewallExtension.
- Settings keep their manual «Сигнальный сервер» path (0.11.13).
