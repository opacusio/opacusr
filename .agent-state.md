## Windows/macOS cross-check technique (learned this session)

CI failed on win/macos clippy for cursor code that Linux could not compile. Now verified locally BEFORE pushing:

```
rustup target add x86_64-pc-windows-msvc aarch64-apple-darwin
cargo clippy -p opacusr-capture --target x86_64-pc-windows-msvc --all-targets -- -D warnings
cargo clippy -p opacusr-capture --target aarch64-apple-darwin --all-targets -- -D warnings
cargo clippy -p opacusr-capture --no-default-features --all-targets -- -D warnings
```

- `cargo check/clippy` needs no linker → works for foreign targets. Limit: crates pulling `ring` (→ opacusr-transport, agent, client) need the target's C toolchain → cannot cross-check locally; their code is platform-agnostic, CI compiles natively.
- Gotchas fixed in `92192de`: windows-sys `HBITMAP` lives in Gdi (not WindowsAndMessaging); `RGBQUAD` has no `Default` (construct explicitly); clippy `chunks_exact_to_as_chunks` fires only on windows path (`as_chunks_mut::<4>()`); empty `Inner` enum on macOS → cfg'd wildcard arms + cfg_attr allow(unused_variables) on shape(); keep `None` arm BEFORE cfg'd `_` to avoid unreachable_patterns.

## Session lessons (2026-11-02)

- **fake pipewire stub**: `bash /home/z/my-project/scripts/fake_pipewire.sh` (headers + .pc files; tarball cached at `/home/z/my-project/fakepw-headers.tar.gz`). Then ALWAYS:
  `export LIBCLANG_PATH=$(python3 -c 'import clang,os;print(os.path.join(os.path.dirname(clang.__file__),"native"))')` and `export BINDGEN_EXTRA_CLANG_ARGS="-isystem $(ls -d /usr/lib/gcc/x86_64-linux-gnu/*/include | head -1)"` — the PyPI libclang (LLVM 18) has no builtin headers.
- **bindgen 0.69 (pinned by libspa-sys 0.8) misparses against LLVM 23** (runner default): structs come out as opaque `_address` blobs. CI/release pin `LIBCLANG_PATH=/usr/lib/llvm-18/lib` + `libclang-18-dev`.
- **macOS runner + bundled OpenH264 is flaky** when e2e tests instantiate codecs concurrently (foreign-exception abort / SIGSEGV). CI now runs the macOS harness with `RUST_TEST_THREADS=1`. One rerun is still cheaper than debugging; `rerun-failed-jobs` endpoint works.
- Rustup after rebuild: `--profile minimal` lacks clippy/rustfmt → `rustup component add clippy rustfmt`.
- `.agent-state.md` is now TRACKED (survives re-clones); `git add -A` includes it — keep it accurate.
- Run `cargo fmt --all` before EVERY commit — CI fails fast on Format otherwise (hit twice this session).
