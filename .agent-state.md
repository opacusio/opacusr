## v0.11.10 SHIPPED (tag on 2fa4854, run 45040897795 success)

Request: «После закрытия окна программы, она пропадает из трея».

Root cause:
- close_to_tray defaulted to FALSE (a deliberate earlier decision after
  the old «висит в трее» complaint), so the window X quit the whole GUI
  process — the tray icon died with it. Existing agent.toml files had
  the false pinned by save().

Fix (commit 2fa4854):
- close_to_tray default flipped to TRUE (TeamViewer/AnyDesk model):
  X = CancelClose + Visible(false); the app keeps serving from the
  tray (agent, consent prompts, file transfers). Real exit = tray
  «Выход» (watchdog + deterministic icon drop) or untick the box in
  Настройки → Хост.
- Migration: new AgentConfig field `config_version: u32` (field-level
  `#[serde(default)]` → old files without the key load as version 0 —
  the container-level serde(default) would have filled the CURRENT
  version and skipped migration!). migrate() flips close_to_tray=true
  once for version<2 and stamps v2; other settings survive; an explicit
  post-update opt-out sticks. deny_unknown_fields forbids renaming the
  field, so version-stamping was the only safe path.
- Settings hint text updated to the new default behavior.
- Tests: close_to_tray_defaults_on, v0_11_9_file_migrates_to_close_to_tray,
  explicit_close_to_tray_false_survives_migration (all green).
- fmt/clippy (exit 0)/workspace tests: 192 passed, 0 failed.
- windows-gnu cargo check for opacusr-app + opacusr-agent: green
  (process_tray is cfg(windows/macos) — Linux build does NOT compile it).
