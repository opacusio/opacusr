## v0.11.23 SHIPPED (326ea3b, release run 45361082990-rerun, ALL GREEN)

User report (0.11.22 installed, screenshot): «не может остановить и
обновить службу на Windows» — MSI upgrade showed the Restart Manager
dialog «The setup was unable to automatically close all requested
applications» and refused to replace files while OpacusR was running.

0.11.23 fix (326ea3b, wix/main.wxs only + versions):
- Root cause: the RM check runs at InstallValidate BEFORE the
  transaction opens; ServiceControl Stop runs after InstallInitialize
  (too late); the per-session agent child is a console process (RM has
  no polite close for console apps); the GUI hides to the tray and
  cancels WM_CLOSE. Deferred CAs cannot run before InstallValidate
  (error 2762) — the fix must be IMMEDIATE actions.
- Fix: 8 immediate WixQuietExec (WixUtilExtension WixCA, already
  linked) actions chained before InstallValidate: setter+exec pairs
  (immediate QuietExec reads and CLEARS WixQuietExecCmdLine, so each
  command needs its own setter) — sc stop OpacusRAgent, then
  taskkill /F /T /IM opacusr.exe / opacusr-agent.exe /
  opacusr-server.exe. Return='ignore' (fresh install: taskkill=128,
  sc stop=1062). ServiceControl Start='install' restarts the service
  after file replacement; exit-dialog checkbox relaunches the GUI.
  Plain uninstall is quiet too (same actions run in all modes).
- Version alignment: workspace deps pinned 0.11.23 (crates inherit
  via version.workspace=true — they can NOT lag), MSI default
  MsiVersion 0.11.23, README-WINDOWS.txt documents the silent update
  path + fixed stale mingw claim (build is MSVC).

## v0.11.21 SHIPPED (5327a67, release run 45337298279, ALL GREEN)

User report (0.11.20 installed): «Неактивна история подключений.
Повторно, нельзя из истории подключиться?» — history rows were plain
labels, taps did nothing; reconnecting meant retyping ID + password.

0.11.21 fix (5327a67):
- history rows are ONE tappable surface each: Frame(INSET, rounding 8)
  re-sensed via ui.interact(rect, Id::new(("history_row", ts, target)),
  Sense::click()) — tap anywhere on the row → App::history_reconnect()
  → prefill peer_id_input + connect_clicked(label). Violet «↻» glyph
  for mobile affordance (no hover on a phone).
- viewer passwords: AgentConfig.viewer_passwords (BTreeMap target →
  password, serde default) saved on ClientEvent::Connected (handshake
  proved the password); agent.toml is 0600 / app-private — same
  posture as the host password. Tap with a stored password connects
  with zero typing; without one the gold message + focused password
  field take over.
- iteration over history clones one row at a time (index loop) —
  history_row needs &mut App while the list is borrowed from it.
